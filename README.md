# 安全巡視日報 & 点検表作成アプリ (Safety Patrol App)

現場での安全巡視日報・巡回点検表の作成、是正改善写真の撮影・添付、および電子押印付きA4帳票（PDF）の出力を、スマートフォンおよびPCから簡単・迅速に行えるWebアプリケーションです。

サーバーへのデータ送信を行わず、すべて端末内（ブラウザ）で完結するため、セキュアかつ高速に動作します。

---

## 🌟 主な機能と特徴

### 1. 📱 スマートフォン単体で現場完結
- iPhone、Androidのブラウザから直接利用可能。
- 「ホーム画面に追加」することで、通常のスマホアプリと同様にアイコンからワンタップで起動できます。
- 現場でスマホカメラを起動してその場で写真を撮影・添付できます。

### 2. 🖨️ A4帳票（PDF）に完全ジャストフィット
印刷（PDF出力）時にブラウザ標準のURLや日時余白を自動カットし、公式様式にジャストフィットしたA4帳票を出力します。
- **1ページ目（日報表面）**:
  - 工事名、巡視年月日、天候、正方形の確認印欄（現場代理人・安全巡視員）
  - 安全巡視員名を入力すると、朱肉風の**本格的な電子丸印が自動押印**
  - 重点巡視項目（2件固定）、安全点検結果（AM/PM）、指示・是正事項
- **2ページ目（巡回点検表裏面）**:
  - オリジナル様式完全準拠（左右各35行・計70行、大項目縦書き結合レイアウト）
  - 項目名が長くても枠内に収まる最適化レイアウト
- **3ページ目（是正・改善写真）**:
  - 写真（改善前・改善後）が添付されている場合のみ、自動で3ページ目を追加出力
  - 罫線が途切れない美しい写真台帳レイアウト

### 3. ⚙️ 工事別項目カスタマイズ
- 工事ごとに点検表の項目を自由にカスタマイズ（「⚙️ 工事別項目設定」）。
- **標準マスター項目**:
  - 一般共通項目
  - 塗膜剥離工事
  - 化学物質管理
  - 電動工具・機器
- 現場独自のオリジナル点検項目も簡単に追加可能。
- 不要になった工事は「🗑️ 削除」ボタンから一括消去可能。

### 4. ⚡ 現場での超高速入力
- **一括入力ボタン**: 「全○」「AM○」「PM○」「終○」「全-」で、35項目のチェックを1タップで一括入力。
- **天候の履歴自動記憶**: よく使う天候（晴、曇、雨、小雨など）を自動記憶し、次回から候補表示。
- **写真の直接撮影 & 選択**: 「📷 撮影」で即座にカメラを起動、または「📁 選択」で端末内のアルバムから選べます。

### 5. 💾 データ保存 & バックアップ・共有
- **自動保存**: 入力内容はブラウザ（`localStorage`）に即座に自動保存されるため、誤って閉じても安心です。
- **保存（エクスポート）**: 入力データをJSONファイルとしてダウンロード保存。
- **読込（インポート）**: 別のスマホやPCでJSONファイルを読み込むことで、入力内容を簡単に引き継ぎ・共有できます。

## 📲 スマートフォンでの利用・アプリ化手順

ブラウザの「ホーム画面に追加」機能を使用すると、専用アプリアイコンが作成され、全画面で使いやすくなります。

### iPhone (Safari) の場合
1. Safari で `https://koyo-shimoyama.github.io/safety-patrol-app/` を開く
2. 画面下部中央の **「共有ボタン（四角から上矢印）」** をタップ
3. メニューをスクロールし、**「ホーム画面に追加」** をタップ
4. 右上の **「追加」** をタップ

### Android (Chrome) の場合
1. Chrome で `https://koyo-shimoyama.github.io/safety-patrol-app/` を開く
2. 画面右上の **「3点メニュー（縦の…）」** をタップ
3. **「ホーム画面に追加」**（または「アプリをインストール」）をタップ
4. 画面の案内に従って追加を完了

## 📖 基本的な使い方

```
[工事・日付選択] ➔ [日報・点検結果の入力] ➔ [点検表の評価入力] ➔ [写真撮影・添付] ➔ [PDF印刷]
```

### 1. 工事の選択・設定
- **工事の選択**: プルダウンから対象の工事を選択します。
- **工事の追加**: 「＋新規」を押し、新しい工事名を入力して作成します。
- **項目のカスタマイズ**: 「⚙️ 工事別項目設定」から、その工事で使用する点検項目（塗膜剥離、化学物質など）を選択・保存します。
- **工事の削除**: 不要になった工事は「🗑️削除」ボタンから削除できます（確認ダイアログが表示されます）。

### 2. 日報入力
- **巡視年月日**: カレンダーから選択します。
- **天候**: 入力欄に手入力するか、候補一覧から選択します。
- **安全巡視員**: 氏名を入力すると、印刷用の印鑑欄に丸印（名字印）が自動生成されます。
- **重点巡視項目**: 重点確認を行う項目を2件入力します。
- **安全点検結果**: 午前・午後の点検概要を入力します。
- **指示・是正事項**: 現場での指示・是正内容を入力します。

### 3. 巡回点検表の入力
- カテゴリごとにカード形式で表示されます。
- カード上部の「全○」「AM○」「PM○」「終○」「全-」ボタンを押すと、そのカテゴリ内の全項目が一括入力されます。
- 指示事項がある場合は「是正・指示」欄に入力します。

### 4. 是正・改善写真の添付（任意）
- 是正・改善事項がある場合、「改善前」「改善後」の写真を添付します。
  - **📷 撮影**: スマホの外カメラが起動し、その場で撮影して即座に添付されます。
  - **📁 選択**: スマホやPCの画像ライブラリから選択して添付します。
- 写真を添付したときのみ、PDF印刷時に**3ページ目（写真台帳）**が自動出力されます。

### 5. PDF印刷・保存
1. ヘッダーの **「PDF印刷」** ボタンを押します。
2. 印刷プレビュー画面が表示されます。
3. **印刷設定の確認ポイント**:
   - **送信先**: 「PDFに保存」を選択
   - **用紙サイズ**: 「A4」
   - **余白**: 「なし」（または「最小」）
   - **オプション**: 「ヘッダーとフッター」のチェックを**外す**（ブラウザの日時やURLの印字が消えます）
   - **背景のグラフィック**: チェックを**入れる**（枠線や印鑑がきれいに印刷されます）
4. 「保存」を押してPDFファイルを保存します。

## 💻 技術仕様

| 項目 | 内容 |
| :--- | :--- |
| **アーキテクチャ** | クライアントサイドSPA（Single Page Application） |
| **コア技術** | HTML5, CSS3, Vanilla JavaScript（外部依存ライブラリなし） |
| **スタイル** | 純粋なCSS（Flexbox, CSS Grid, 印刷用メディアクエリ `@media print`） |
| **データ永続化** | ブラウザ `localStorage`（端末ローカル保存） |
| **電子印鑑** | インラインSVG動的生成（朱肉風二重枠丸印、明朝体レンダリング） |
| **写真処理** | HTML5 File API + Canvas / DataURL 変換 |
| **デプロイ環境** | GitHub Pages（静的ホスティング） |

## 🔄 アプリの更新方法（管理者向け）

ローカルの `index.html` を修正した後、Web版に反映する手順：

1. ブラウザで [GitHub リポジトリ](https://github.com/koyo-shimoyama/safety-patrol-app) を開きます。
2. 画面右上の **「Add file」** ➔ **「Upload files」** を選択します。
3. パソコンの `index.html` をドラッグ＆ドロップします。
4. 下部の **「Commit changes」** をクリックします。
5. 約1〜2分で GitHub Pages に自動反映されます。
